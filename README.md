### 🚀 About Me / O mnie

I am an **IT Support & Systems Automation Engineer** passionate about building high-performance, rock-solid desktop applications and administrative automation solutions for corporate networks, retail store POS environments, and Active Directory domains.

- 🛠️ **Engineering Focus**: Designing bulletproof **C# .NET 10 (WPF)** client tools and **PowerShell** one-liners that overcome remote management limitations (BeyondTrust Remote Support, UAC, Double-Hop Kerberos authentication, and restricted ExecutionPolicies).
- 🏢 **Enterprise Workflows**: Active Directory diagnostics, Windows LAPS & Legacy LAPS password retrieval, REST GenericInterface integration with ticket systems (**OTOBO**), silent USB printer fleet deployment (**Xerox & HP LaserJet Enterprise**).
- 🔒 **Security-First Approach**: Adhering to the Principle of Least Privilege, DPAPI cryptographic credential protection, zero plain-text passwords, and strict compliance with corporate SOC/EDR standards.
